# FlashLearn - Flashcard Quiz App

## About the Project

FlashLearn is a Flutter-based flashcard quiz application designed to help users learn and revise information using flashcards. The app provides a simple and user-friendly interface for managing and reviewing flashcards.

## Features

- View flashcards
- Navigate between flashcards
- Edit flashcards
- Manage flashcard data
- Local data storage
- State management using Provider
- Simple and user-friendly interface

## Technologies Used

- **Flutter** – Cross-platform application development
- **Dart** – Programming language
- **Provider** – State management
- **Hive** – Local database and data storage
- **Material Design** – User interface design

## Getting Started

### Prerequisites

Before running this project, make sure you have installed:

- Flutter SDK
- Dart SDK
- Android Studio or Visual Studio Code
- An Android emulator or a connected device

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/ahmadjamshid418-gif/CodeAlpha-project.git
   ```

2. Navigate to the project directory:

   ```bash
   cd CodeAlpha-project
   ```

3. Install the project dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```
